# Retain the raw receipt analysis with the photo

The receipt reader used to keep only the receipt text and the fields it mapped for each item (description, quantity, prices and line text), discarding confidence, line positions, product codes and tax details. Improving the parser therefore meant paying to rescan photos, and misreads could be investigated only from the text, not from what Azure actually read. The owner chose to store the complete raw analysis result with each scanned receipt and to delete it together with the photo after six months. Parsing becomes a replayable step over stored evidence: parser changes can be re-run and benchmarked offline against earlier scans. Keeping only the mapped fields was rejected because every new field would again require rescans, and keeping nothing was rejected because it rules out offline benchmarking.
